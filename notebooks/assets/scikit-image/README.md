# Chelsea the cat (scikit-image sample image)

`chelsea.png` is `skimage.data.chelsea()` (also `skimage.data.cat()`), 451 × 300 RGB, copied
unchanged from the scikit-image repository: `src/_skimage2/data/chelsea.png` in
<https://github.com/scikit-image/scikit-image>.
