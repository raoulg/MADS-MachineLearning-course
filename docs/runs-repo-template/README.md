# MADS Machine Learning: class runs

The runs everyone in the class submitted, one JSON file per mlflow run:

    lesson<N>/<github-login>/<run_id>.json

Write only inside your own directory, and only with `scripts/submit_runs.py` from the
course repository: the files are generated, not hand-edited. Every push is validated; a
push that writes into someone else's directory, or a file that does not fit the format,
fails the check.

How to submit: `docs/submit-runs.md` in the course repository. The format:
`scripts/run_submission.py` there.
